AI for Sustainable Development – SDG 2: Zero Hunger

Project Title: Predicting Crop Yields for Sustainable Agriculture using Machine Learning

Problem:
Farmers face declining yields due to changing climate patterns and inefficient resource use. Unpredictable yields lead to food insecurity and economic loss.

Solution:
A supervised machine learning model (Random Forest Regressor) predicts crop yields using features such as rainfall, temperature, soil pH, fertilizer use, and land area. The model supports data-driven decision-making for efficient agricultural planning.

ML Approach:

Type: Supervised Learning (Regression)

Algorithm: Random Forest

Tools: Python, Scikit-learn, Pandas, Matplotlib

Dataset: Open agricultural data from FAO/World Bank/Kaggle

Results:

Mean Absolute Error: ~2.5

R² Score: ~0.86

The model effectively estimates future yields with high accuracy.

Ethical Reflection:
Bias may arise from uneven regional data coverage. Mitigation includes diverse datasets and cross-validation across regions. The solution promotes fairness by being open-source, empowering smallholder farmers globally, and advancing sustainable agriculture.

Impact:
Supports SDG 2 – Zero Hunger by enabling predictive, sustainable, and data-informed farming practices that enhance food security and reduce waste.
